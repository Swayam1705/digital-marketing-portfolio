RESUME PLACEHOLDER
==================

Place your resume PDF in this folder and name it:

    your-resume.pdf

So the full path is:

    public/resume/your-resume.pdf

The "Download CV" button already points to:

    /resume/your-resume.pdf

If you name the file something else, update the `resume` field in:

    src/data/portfolioData.js

Example:

    resume: "/resume/jane-doe-cv.pdf"

You do NOT need to write any component code for this to work.

Until a PDF is added, the website shows a friendly on-page note
explaining that the resume is not available yet (no broken download).
